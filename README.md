## Getting Started

### Installation

This project uses [mise](https://mise.jdx.dev) as a toolchain manager to handle all development dependencies, including Rojo.

1. **Install mise**: Follow the [mise installation guide](https://mise.jdx.dev/getting-started.html).

2. **Install project dependencies**: Once mise is installed, run the following command in the project directory to install all required tools (including Rojo):
   ```bash
   mise install
   ```

3. **Install Roblox (Wally) packages**: After mise dependencies are installed, run Wally to install project packages:
   ```bash
   wally install
   ```
   
   If packages have been downloaded in `Packages/`, generate type definitions:
   ```bash
   wally-package-types -s sourcemap.json Packages/
   ```

4. **IDE Setup**: Make sure you have [Roblox Studio](https://www.roblox.com/create) installed and set up.

5. **Visual Studio Code Extensions** (recommended):
   - [Rojo](https://marketplace.visualstudio.com/items?itemName=evaera.vscode-rojo)
   - [Luau Language Server](https://marketplace.visualstudio.com/items?itemName=JohnnyMorganz.luau-lsp)
   - [Stylua](https://marketplace.visualstudio.com/items?itemName=JohnnyMorganz.stylua) (Lua formatter)
   - [Selene](https://marketplace.visualstudio.com/items?itemName=Kampfkarren.selene-vscode) (Linting)


### Building and Running
To build the place from scratch, use:

```bash
rojo build -o "fullstack_project.rbxlx"
```

Next, open `fullstack_project.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

## Managing Wally Packages

To add a new Wally package to your project:

1. Visit [https://wally.run/](https://wally.run/) and search for the package you need
2. Click the "Install" box to copy the installation string
3. Open `wally.toml` and paste the string in the `[dependencies]` section
4. Run the installation command:
   ```bash
   wally install
   ```
5. If packages were downloaded, generate type definitions:
   ```bash
   wally-package-types -s sourcemap.json Packages/
   ```

## Deployment

To deploy your place to Roblox, you can use the `rojo upload` command.

```bash
rojo upload --asset_id [PLACE ID] --cookie "[SECURITY COOKIE]"
```

If you are on Windows and have Roblox Studio installed, --cookie is optional and will be pulled from your Roblox Studio session if not specified.

For more help, check out [the Rojo documentation](https://rojo.space/docs).
